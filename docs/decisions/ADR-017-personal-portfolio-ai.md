# ADR-017：隔离个人账本、收益比较和证据驱动复盘

日期：2026-09-07。对应已批准的 SPEC-SHM-002 v0.1。

## 决策

1. 新模块为 `shm.personal`；个人事实、估值、报告和设置写入独立 `portfolio.sqlite3`。原 `service.sqlite3`、V04/S500 账本、选股与历史研究没有迁移或覆盖。
2. 账本以不可删除的事件与冲正关联为事实源。FIFO 成本批次、净现金和交割义务由同一 Decimal 引擎重放，避免预览、提交及修订存在两套算式。首版一个 USD 账户，重放规模足够小，每个已提交版本同步保存包含 FIFO 批次的 ledger_snapshots，重放仍是唯一计算来源。合约信息嵌入事件，完整合约键用于聚合，不引入重复维护的合约主表。
3. 预览不写库，摘要绑定账本版本和原始请求。事务提交再次重放完整受影响时间线；幂等编号及请求哈希防止重试重复入账。修订保留原记录，标记之后的估值待重核，不重写历史 AI 报告。
4. 成交权利金与费用进入 FIFO 成本。行权/指派转入股票成本或卖出收入，不二次记现金或独立期权平仓盈亏。期初原始成本未知时，仅保留观察期基准，不编造真实已实现收益。
5. 账户收益依据、持仓归因、对账三个状态分开。缺合约报价时不计算账本合计；有理由且资金流完整时可选券商净值。日线比较只支持共同收盘起点；盘中现金流缺少即时估值时明示 Modified Dietz。内部缺日保留断点，不给完整区间最大回撤。
6. 个人正股估值用 `as_traded_close`，SPY 对照用含息 `close`。个人行情复用缓存、锁和 600 次调用预算，在模拟任务完成之后刷新；个人摘要另存，避免覆盖策略覆盖率。期权报价由用户录入。
7. 私人接口由已有 HTTPS 认证网关保护，后端验证网关专用随机凭据。没有完整配置及绕过验证时关闭。服务端 Fernet 密钥文件和数据库分离。前端不持久保存账户或 API 密钥；API 不返回密钥。
8. AI 独立线程负责有界作业。程序先计算证据和输入哈希；模型只解释这些数据，JSON 结构及引用通过后才保存结果。缺样本或缺估值的标题由程序限定。采纳只改建议状态，导出才形成供人评审的实施任务。

## 边界与限制

- 不计算券商购买力、完整保证金或期权 Greeks；交割总额不是最大亏损。
- 非标准合约可保存及平仓、人工现金结算；自动实物交割仅支持已明确的标准合约。换股/合约替换必须有依据，复杂混合交付暂存待核。
- 真实成交通常是事后补录，因此附带计划不当成事前计划，也不据此评分纪律。原始建仓日期未知时不计算持有期。
- 个人每日估值由用户预览并确认，尤其是期权、资金流及券商对账；未录入日不自动补成已知净值。
- 首版账户与合约采用版本化 JSON 事实存储；若未来数据量需要索引或物化批次，通过新迁移增加，当前不预先扩展。
- 数据库修订、设置及建议状态保留审计。回滚代码或关闭私人功能保留数据库和独立主密钥。

## 迁移

`PortfolioStore.initialize()` 执行幂等 schema v1（`PRAGMA user_version=1`），创建 account、account_history、events、submissions、ledger_snapshots、valuations、settings、reports、attempts、suggestions、audit。SQLite WAL + `BEGIN IMMEDIATE` 用于写事务。已高于 v1 的数据库拒绝降级写入。私人功能禁用时不打开个人数据库。
