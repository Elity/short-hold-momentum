日期：2026-09-07。状态：已实施。Owner已明确授权数据修复、固定候选复跑和部署；合格胜者才启动新模拟账户。

## 问题与决定

历史资格计算曾用今天的复权价判断5美元门槛。AAPL在2005-01-03实际收盘63.29美元，当前复权值约0.95美元；以复权值判断会错误排除。现将当时报价和当时成交额与复权行情分列。Yahoo单次证券请求取得未分红调整价格、复权价和公司行动；用后续拆股还原当时报价，Close×Volume计算成交额。S500研究、日常行情队列和模拟盘共同要求该口径，不改变C0–C4参数。

旧缓存完整备份后升级。复权OHLC继续服务动量、收益和退出；严格资格字段缺失时不得新增风险。此次队列完成510个证券（当前503成分、SPY和旧名单额外证券），保留每日600调用上限、串行间隔和429暂停。报价新鲜与资格字段完整分开展示。

原历史成分文件截至2026-06-30，原字节及哈希保留。补充47个交易日，按生效日期应用官方公告；临时MBGL成员依据官方分拆规则与时间重建，标明推断，不宣称取得授权逐日指数名单。未提前应用9月21日调整。

旧、新股票代码映射必须同时有发行人身份或公司行动证据；重叠价格可辅助核验，不能独立证明身份。KORS与CPRI是同一发行人：重叠区间使用显式修正消除重复，并保留原源文件。研究使用规范身份代码，不声称其为当时交易代码。未知重复继续阻止加载。

公开WIKI归档截至2018年，含原始及复权OHLCV、分红与拆股。补入原本完全缺失的价格序列，不填造缺日、不外推停更后的数据，不覆盖已有原始缓存。新增序列属于诊断数据，身份、现金收购、换股及退市结算尚未完整核验，不能仅凭覆盖率改善判定通过。

TIE缓存混入其他证券的万位价格，与SEC披露的股价区间矛盾；其另一免费来源也存在缺日、缺量和OHLC矛盾。WIKI的MIL对应MFC Industrial，与历史成员Millipore不符。两者隔离，仍保留在历史成员和覆盖率分母内。未解决证据统一纳入候选晋级闸门，无法产出winner或新账户。

持仓价格质量检查增加前收盘到实际卖出价的跳变；修复假卖出开盘可能制造虚假收益的盲点。末日估值、10/25bps成本、评价截止日和共同基准不变。
