# 美股动量轮动与趋势退出

## 目标与边界

同区间、税前、扣交易成本后的 CAGR 高于 SPY 买入持有，最大回撤绝对值小于 SPY。10% 回撤是优化目标与预警线：记录并生成复盘，不强制清仓。不设最长持仓期限。趋势持续且继续入选可以续持。

股票池使用 owner 原84只名单及原 exclusions，每个时点重新判断资格，不沿用开发期固定48只子集。本轮先验证正股；期权仅草稿，修复风险联动，不计权利金收益。免费日线数据、不融资、不卖空、先模拟的约束保留。

## 共同交易规则

- 126个交易日动量，跳过最近21日，前15名等权；沿用原 XNYS 日历锚点，每20个交易日选股、定仓、补仓或恢复仓位。
- 资格只看截至信号日的数据：最近260个交易日历史完整、价格>=5美元、ADV60>=1000万美元，并通过当期数据质量检查。上市前缺数不构成永久排除。
- 资格少于30只，暂停新增买入并记覆盖不足；已有持仓仍执行风险退出。
- 继续入选且未触发退出则续持；落出前15名定期调出。普通日只允许风险卖出，其余股数不变，资金留现金。
- 收盘后形成信号，下一交易日开盘执行；风险退出优先于调仓买入。同日退出股票的份额保留现金，不补选、不重新分配。
- 跳空按实际开盘价；缺报价保留未成交记录，不按前收盘价或止损线伪造成交。未成交风险卖出持续待处理；开盘买单未成交不自动跨日追买。
- 仓位最高100%，不杠杆；仅定期选股时按最近20日篮子波动率确定仓位。

## 固定候选

| ID | 定义 | 目标年化波动率 |
|---|---|---:|
| C0 | V04规则，改为84只当期资格 | 15% |
| C1 | C0 + 每日SPY200趋势退出 | 15% |
| C2 | C1 + 个股SMA50退出/入场过滤 | 15% |
| C3 | C1 + 3倍ATR20跟踪退出 | 15% |
| C4 | C1的较高仓位预算 | 20% |

C0也参与最终选择。不扩参数网格，不叠加SMA与ATR；保留旧V04为存档参照。C0保持原20日市场风控节奏，每日仍记录净值与回撤。

- C1–C4：SPY close<=SMA200，生成全部正股次日退出意图、禁止新增风险；重新站上均线后等待下一选股日恢复。
- C2：个股 close<=SMA50，下一开盘全部退出；定期选股日也不买这类股票，原份额留现金。
- C3：TR=max(high-low, abs(high-prev_close), abs(low-prev_close))；ATR20为最近20日TR简单平均。初始跟踪线=实际成交价-3×成交前已知ATR20。
- 持仓峰值=max(实际建仓成交价, 建仓后所有收盘价)。每日跟踪线=max(上一跟踪线, 持仓峰值-3×当日ATR20)。close<跟踪线，次日全部退出。
- 加减仓和跨调仓续持不重置状态；全部退出后重建才重置。ATR可能在尚未盈利时触发。复权尺度变化同步调整持仓风险状态。

## 研究协议与选择

截至2026-09-04的行情全部标为已知历史研究集；v0.3显式允许本次固定候选复核，不将其称为新OOS，不重置或写入v0.2的三次OOS账本。

主区间为2005年起完成260日预热后的共同区间，截止2026-09-04。所有候选使用相同数据快照、84只名单、评价起点；SPY从共同起点买入，不等待各候选第一次交易。另固定展示2019年后、逐年、剔除最佳年结果。

同一含分红总回报口径，现金收益0；股票和SPY都计单边10/25bps，末日按收盘估值。展示相同风控和波动缩放的SPY辅助对照、历史时点成分股敏感性及其覆盖率。原84只名单的事后选择偏差仍披露。

晋级同时满足：正确性与关键数据检查通过；10bps净CAGR>SPY且abs(MaxDD)<SPY；25bps下两条件仍成立。选择排序：25bps超额CAGR降序、25bps回撤绝对值升序、换手升序、规则模块数升序、ID升序。10%不作淘汰线。

单年依赖、股票池敏感性、PIT覆盖不足单独展示，不被PASS掩盖。关键行情不完整时不能给有效策略结论。无人晋级则记录本轮未达目标，不追加候选、不放宽条件。历史通过仅表示值得前向验证。

## 实现与模拟

- 回测和paper共用收盘决策及成交函数，持久化实际持仓、建仓信息、峰值、跟踪线、最后处理日；持仓>260日仍可续算。
- 按strategy_id隔离票据、成交、账户和报告；V04默认兼容、旧配置/记录/账户保持。rebalance与risk_exit事件区分，后者不算完整调仓周期。
- 仪表盘增加版本、退出原因、峰值、跟踪线、回撤预警、历史筛选与前向状态；不同起点不混比。
- v0.3同时维护10/25bps模型成本账本。官方开盘价和模型成本不构成实测券商执行证据。
- 缺关键行情禁止新增风险，记录未完成决策；重跑与重启幂等，错过决策不得伪装为当时及时生成。
- 期权风险关闭禁CSP；待卖股票禁新增CC；CSP服从股票+期权合计敞口、原20%名义上限及现金覆盖。草稿收益不入账。
- 只有合格胜者冻结后，才从下一选股日起建立独立10万美元模拟账户；旧V04保留。3周期+3月报验收运行，满12个月才评价完整年前向目标；更短期只突出累计收益和相对SPY表现。

## 验收

覆盖无前视/次日开盘、跳空与缺报价、ATR单向状态与复权、日间卖出不补仓、冲突优先级、上市资格与260日窗口、重跑与重启、回测/paper一致、risk-off禁正股与CSP、V04数据隔离。交付规格、ADR、预注册、统一研究报告及存在合格胜者时的独立模拟配置。
