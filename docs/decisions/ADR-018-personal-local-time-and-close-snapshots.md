# ADR-018：本地时间输入与自动收盘资产快照

日期：2026-09-07。依据用户对日期换算、重复录入及自动市值计算的反馈，补充 SPEC-SHM-002 v0.1，并替代 ADR-017 中每日正股估值必须由用户再次录入的约束。

- 日期时间输入采用浏览器本地时区，提交时转换为明确时间戳；显示也转换回本地时区。合约到期日、报告交易日保留美股日期语义。
- 期初账户本身就是已持久化的资产事实，读取时直接生成首次快照，不复制账户数据、不改变旧事件或数据库版本。
- 每日策略任务全部尝试完成后，再刷新个人持仓及 SPY 的共享日线缓存，生成独立个人收盘快照。手动更新股价复用同一入口，模拟任务活动时不抢先运行。
- 自动快照按收盘时重放账本，使用名义收盘价和已录入现金流水。新价格必须属于目标收盘日；待修复行情、缺期权价格和已标记待确认公司行动不生成完整资产值。没有券商净资产时不伪造对账一致。
- 同一收盘和相同输入去重；修订保留旧版本；用户已有同收盘来源选择优先。读取页面可用已有缓存补算最新完成交易日，不新增全市场扫描或实时行情服务。
- 默认以已录入账本完整为计算前提；券商对账是可选的额外核验。入出金、现金分红、税费、融资利息、公司行动及期权事件仍由用户如实记录，系统不推断未录入事实。

本轮只交付这些交互及自动计算改进，不调整策略、回测参数、股票池或 AI provider 设置。回滚保留个人数据库；新增自动快照与既有 schema v1 兼容。
