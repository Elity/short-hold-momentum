# SHM 个人账户与 AI 复盘操作说明

## 建账与日常录入

从 HTTPS 认证入口打开「个人账户」。建立一个 USD 账户，填写准确的期初时点、净现金、同一时点的券商净资产和所有持仓。期初股票数量可为碎股；空头数量为负；期权价格填写每股权利金，标准合约乘数为 100。原始成本、建仓时点未知可留空，不影响从期初市值开始观察。

普通交易从持仓行「记录操作」带入对应证券；通用入口必须明确方向。费用必填，可以为 0。多腿先逐腿「加入本次组合」，一次预览及提交。展期是旧合约平仓腿和新合约开仓腿，可用组合编号关联。预览显示原持仓、本次变化、最终持仓、净现金和交割总额。交割总额不代表保证金或最大亏损。

现金事件区分入出金、分红、利息收入、融资利息和费用。分红填写税前金额和扣税，再投资另记买入。期初应收到账或应付结清选择对应的内部转移事件，不作为入出金或再次计收益。保证金账户负现金代表融资，交易须确认融资事实，不能再把借款作为第二笔负债扣减。

期权到期、行权和指派必须按券商实际确认录入；不会自动在到期日按零关闭。实物交割同步股票与现金，之前的权利金转入股票成本或有效卖出收入。现金结算填写未扣本次费用的有符号总额。非标准调整合约、混合交付或无法核实的公司行动先标记待核。

录错通过流水「修订」提交冲正与替代记录；原记录不删除。若修改影响后续可平数量，服务端拒绝不成立的时间线。重试保留原提交编号；并发冲突后页面保留草稿，更新版本并要求重新预览。浏览器关闭后草稿不保留。

## 每日估值与比较

在已完成交易日收盘后录入估值。正股从名义价格缓存带入；期权填写同日券商单位估值。覆盖说明须明确已包括哪些交易与资金流；同一时点表示包括截至该时刻的全部有效事件。盘中资金流前后的估值用不同且准确的时间戳，不能把同一时间戳同时解释成流入前和流入后。

收益来源可选持仓账本或券商净资产，也可暂存待核。缺合约报价时，账本合计和对账差额显示不可计算；选券商净资产并确认资金流完整后可算账户收益，持仓归因仍显示不完整。有差额时须填写来源依据，不会因选择来源而变成已对账。

「资产表现」按共同收盘起点比较个人账户、所选模拟前向账本和 SPY。SPY 采用含息收益，首日扣模型买入费用；个人使用实际费用、融资利息和税后分红。不足一年主要看累计收益，不用短期年化宣告目标。缺日曲线断开，完整区间最大回撤和排名关闭。模拟没有前向记录时显示等待，不接入历史回测。

## AI 设置及报告

在「AI 设置」填 Base URL（通常以 `/v1` 结尾）、精确模型 ID 和密钥。先保存，再测试。读取配置不返回密钥，密码框留空表示保留已存密钥。更换接口、模型或密钥后须重新测试。

选择允许发送的个人/模拟数据范围。默认自动发送关闭，开户者确认范围后开启；关闭发送仍保留周期。周六 08:00 北京时间生成上一周简报，每月 1 日 08:15 生成上个自然月复盘。账户不足完整月份时报告受限。默认每月最多 8 次自动尝试、每日 4 次手动尝试；暂时故障最多重试一次，重试计额度。单次最多 6,000 completion tokens、证据包 200,000 字符。额度可调低，不可越过首版上限。

「AI 复盘」先选择个人/模拟页签，再选报告的类型、区间和版本。失败或受限状态显式显示。量化事实引用程序证据；缺成本、估值或前向样本时不推断完整表现。建议最多三条，包含范围、验收和停止条件；采纳只改变待办状态，导出 Markdown 才形成待评审任务。AI 不改代码、参数、账本或订单。

## 认证、部署与恢复

继续使用原服务及既有认证网关，新增部署变量：

| 变量 | 用途 |
|---|---|
| `SHM_PRIVATE_ENABLED=1` | 开启私人模块；默认关闭 |
| `SHM_PUBLIC_URL` | 认证后的 HTTPS Origin，不带路径 |
| `SHM_GATEWAY_TOKEN_FILE` | 后端随机服务间凭据文件路径，至少 32 字符 |
| `SHM_GATEWAY_VERIFIED=1` | 完成未登录、伪造头和直连绕过测试后才设置 |
| `SHM_AI_MASTER_KEY_FILE` | 独立 Fernet 主密钥文件，权限 0600 |
| `SHM_PORTFOLIO_DB_PATH` | 默认与 service.sqlite3 同目录下的 portfolio.sqlite3 |

认证网关须先认证，再覆盖转发 `X-SHM-Gateway-Token`；不能把凭据发给浏览器。拒绝客户端伪造该请求头。私人写请求的 Origin 须匹配 SHM_PUBLIC_URL。原 HTTP 端口缺凭据时不得读写个人数据；`/api/dashboard` 不含个人数据。网关 Origin、令牌和 HTTPS 配置不完整时保持私人功能关闭。

首次启用前备份 `service.sqlite3`、运行目录以及已有的个人数据库、独立主密钥和 compose 配置。运行中 SQLite 使用 Backup API，不仅复制主文件而遗漏 WAL。更新为不可变镜像 SHA；保留旧镜像以便回滚。使用独立临时运行目录和验收账户走完整闭环，再启用真实入口，不能向真实账本写入演示账户或假交易。

回滚：恢复旧镜像或 `SHM_PRIVATE_ENABLED=0`，保留 `portfolio.sqlite3` 及密钥。首次数据库初始化自动完成 v1 建表；没有修改原 service.sqlite3 的结构。主密钥丢失将无法解密已保存接口密钥，须重新填写；账本数据仍在。

## 首版停止条件

固定账务及浏览器场景通过、原系统回归通过、部署备份及认证绕过验证完成后结束。三个完整调仓周期和月报属于策略运行验收，不以这个功能迭代追加股票池研究或参数搜索。未经真实服务商调用验证时，验收记录明确说明采用替身模型。
