# SPEC-SHM-001 v0.4 — 可核验的跨行业标普500股票池

状态：owner于2026-09-06明确要求调整股票池后部署。

## 唯一策略研究变化

沿用v0.3的C0–C4五组规则、成本、共同评价日期和收益/回撤验收；以历史时点标普500成分替代AI/科技owner名单，编号S500-C0–S500-C4。不同时加行业上限或优化参数；报告行业集中度。已经观察过的历史仍标known_history，不是新OOS。保留owner原名单、V04和v0.3全部记录。

历史成分缺失、退市证券报价污染或异常持仓价格跳变使结论INCONCLUSIVE；不把今天的503证券名单倒灌到2005年，不删除不利股票来制造收益。不合格时无winner、无新前向账户；数据与仪表盘能力仍可部署。

## 2026-09-07 数据修订

策略参数及晋级标准不变。5美元价格门槛使用当时实际报价，ADV60使用当时成交额；动量、ATR与收益使用含分红复权价。S500研究与模拟盘必须具备这两类数据，不能用今天的复权价反推历史股票是否达到价格门槛。拆股调整通过公司行动还原；无法确认时暂停新增风险。

历史成分保留原CSV，通过哈希固定的补充清单扩展至2026-09-04。更名使用同一证券的规范身份，不能解释为新代码当时已经使用。明确证据支持的重复发行人采用逐段修正，并校验原行和修正数量；其他重复仍拒绝加载。

退市股票归档只作补充输入，保留来源、原文件与哈希。已发现的错证券行情隔离，仍保留历史成员与覆盖率分母。归档未覆盖的退市结算、现金收购、换股和后续价格，以及尚未核实的身份，必须留为未解决证据并阻止晋级。检测持仓异常价格时同时检查真实卖出成交价，不能只检查当日收盘价。

本次修复说明见[ADR-013](decisions/ADR-013-point-in-time-data-remediation.md)。数据修复后的复跑仍是已知历史研究，不新增OOS记录。

并购与代码复用的进一步修复见[ADR-014](decisions/ADR-014-corporate-actions-and-security-identity.md)。模拟账户按已核实的默认条款转换权益，现金先列应收，固定于有效交易日之后第5个XNYS交易日释放。该到账规则为预先固定的模拟假设，不能称实测；缺对价、证券身份或必要价格时仍不能晋级。研究保留小数权益，整股模拟还须明确适用的零股现金规则。

## 当前成分与新鲜度

通过实际State Street SPY产品页提供的完整每日持仓XLSX，与Wikipedia标普500成分表交叉核验。发行人ETF持仓并非实时授权指数数据；明确保留来源持仓日期、实际抓取时间、核验时间、URL和原始文件哈希，不声称绝对实时。

剔除可明确识别的现金/非股票权利并记录理由；两源股票集合须一致。每项保存canonical symbol、Yahoo symbol、名称、CIK、CUSIP/SEDOL、行业、币种。500家公司可以对应503证券。异常规模、重复、身份不一致、异常大幅变更不能静默替换last_good。

每日围绕最新完成交易日核验一次（同一UTC日成功后重跑零来源请求）；来源as_of和验证交易日距最新完成XNYS交易日均不得超过1个交易日。失败、双源不一致或过期，保留上次合格快照用于展示和风险处理，但禁止新增买入。每次成分变更保存不可变快照和add/remove差异；不得用fetched_at冒充来源日期。

## 独立行情队列

收盘后先核验股票池，再更新SPY和持仓，其余当前成分串行补齐。默认请求间隔至少1秒，每日最多600次provider.history调用；Yahoo内部cookie请求不假称只有一次HTTP请求。429/Retry-After触发全局暂停，整体工作流重试不得绕过暂停与预算。

本地当日行情完整则零网络请求；尾部更新含最近5交易日重叠比对，若复权历史变化，归档旧缓存并重新抓取该证券完整历史，不猜测复权因子。空响应、内部缺口、不完整复权历史不能被记录成成功。先更新少量已有缺口，不重复下载全美股。

仅完整同日价格快照且成分新鲜，才允许产生新仓位；否则保持已有风险退出机制。股票池更新、行情抓取、策略计算分离，选股计算只读本地快照。current source通过不等于市场趋势允许风险，也不等于研究已通过。

## 运行与部署

S500-*使用config/v04、reports/v04和paper/v04的独立记录，并复用共享C0–C4算法与10/25bps账本。合格winner才初始化10万美元模拟账户。每日运行与页面展示名单日期/核验状态、证券与公司数、来源、差异、数据完整性及是否允许新风险。

保留NAS现有持久目录与SQLite设置（现场每日时间07:30），使用不可变镜像SHA部署。先拉镜像，再短暂停服务并完整备份runtime与compose；替换后核对端口、健康、旧账本哈希、新股票池和调度设置。保留旧镜像与备份供回滚。无实盘下单授权。
