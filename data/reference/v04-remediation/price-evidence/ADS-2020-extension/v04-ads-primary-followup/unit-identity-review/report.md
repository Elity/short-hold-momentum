# ADS 身份与名义单位独立复核

**现有发行人文档支持旧 Alliance Data Systems 的普通股身份和所检查的名义价格单位。2016–2017 八季价格区间及四个明确收盘价锚均通过；尚不代表所有历史行动、成交量或每日价格已获独立认证。** 本次零联网、仅读取父任务提供的正文与已有本地行情，未建 candidate、未改仓库。

## 身份、股类与来源等级

2017、2019 年报和 2020-04-23 8-K 的法定发行人均为 **Alliance Data Systems Corporation**，Delaware 公司，IRS **31-1429215**，SEC file **001-15749**；证券为 **Common stock, par value $0.01 per share**，NYSE 代码 **ADS**。年报镜像 accession 和2019正文 XBRL 指向 **CIK 0001101215**。2020声明明确现金针对公司的 common stock，不是优先股、子公司少数权益或员工奖励单位。

2017/2019 材料来自 **EDGAR Online 的发行人年报镜像索引正文**，不是本子任务直接从 SEC 下载的原始完整年报。2017 源在后续附注 F-21 附近截断，2019 源在 MD&A 前段终止；不能因字符串 `split` 未出现就断言完整时期没有拆股。2020 材料为 SEC 地址8-K索引正文和发行人PRNewswire通稿索引正文，按实际取得来源分别保存哈希。

2019 正文开头含 XBRL 标签和 U+200B；仅在本子任务检索/摘录时去除零宽字符并统一空白，未覆盖原文。没有采用同批 Delta、Apple 等其他发行人的结果。

## 股本变化与非普通权益边界

2017 年报已取得的完整2015–2017股东权益变动表以**百万**为单位：issued common shares 从2015年初111.7变为年末112.1、2016年末112.5、2017年末112.8；表列股薪、回购、Other等变化，没有另列 stock split 行。2017/2016年末 treasury shares 为57.4/55.1百万；这些是公司自身已发行/库存股总数，不是价格文件中一股应乘的倍率。2018-02-21 封面精确 outstanding 数为55,461,323股；2019年报披露2020-02-20 outstanding为47,627,611股。不能把发行股数和流通/在外股数的差异当拆股。

该表中 **Accretion of non-controlling interest**、stock-based compensation、2017年的 **Dividend equivalent rights $0.9 million** 等是不同会计项目，不能转成每名ADS普通股持有人的额外现金。普通股现金已有明确 Item 5 的每股表，金额复核由父任务单独完成。

2019所取正文没有完整后续股东权益表；2020只取得4月23日宣告资料，未取得2020Q2 10-Q的实际支付/半年股本变动附注。它们支持同一普通股身份、名义单位及所声明金额，不能扩大成“已核实2018–2020全部股本动作”或“2020Q1/Q2实际均已支付”。本子任务不从因子推金额，也不对缺附注作反向猜测。

## 可以推进及仍未闭合的部分

可以把“只有供应商公司名”升级为：**有发行人镜像/SEC索引正文身份、两期年报一致股类、2020同一普通股延续、八季高低价和四处名义价锚支持**。未发现要求否定这部分身份/单位证据的实际冲突。

仍须分别处理父任务的两笔旧漏息、尾部普通股现金、精确日期来源等级、整体名义单位和source差异；本复核不认证整个2012-12-12至2020-07-02窗口的每根bar或每项公司行为。也不要求重建2021分拆、2022改名等窗口之外生命周期。

`primary-unit-excerpts.json` 保存实际段落，`source-index.json` 固定所有已读源哈希，`checks.json` 记录核对结果，`review_units.py` 可零网复现。批准范围仅为此独立证据复核，不批准价格应用、manifest变更或研究晋级。
