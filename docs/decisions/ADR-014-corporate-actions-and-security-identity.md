# ADR-014：公司行动、证券身份与模拟结算

日期：2026-09-07。状态：在修复后的候选收益复跑前确定。Owner已授权逐步自主完成；五个候选、收益/回撤门槛、10/25bps模型成本和历史截止日保持。

## 公司行动记账

并购导致原证券消灭时，按正式文件中的默认现金及换股条款转换权益。原证券最后交易日后不得虚构开盘价；已有污染尾段必须按有证据的终止日截断。对价、来源、最后交易日、有效交易日、单位换算和状态转移进入独立事件账，不冒充市场成交，也不向强制换股收取交易模型成本。

研究和模拟账户的持仓数量以复权价格为单位。若复权价=当时实际价格×f，实际权益股数=q×f。现金为实际股数×每股现金；继受证券的复权数量为实际股数×换股比例÷继受证券f。已嵌入复权行情的普通股息或拆股不重复发放；只有终止原证券的额外权益走本模块。

没有既有继受持仓时，按经济价值转换原持仓的成本、峰值和ATR线；已有继受持仓时，按普通加仓合并成本与数量，沿用该持仓的既有ATR状态。旧股已排队退出时，只卖掉其对应的继受数量，不能连带卖出原来持有的继受股票。完全退出及重建仍遵循既有策略。

## 固定结算模型

公开并购文件确定的是法律权益，通常不提供每个券商账户的入账日期。该系统为电子记账的模拟账户，采用统一的 **有效交易日之后第5个XNYS交易日** 释放现金规则。该选择先于本次修复后的收益复跑，不按回测结果调整，不新增候选或参数搜索。

这是一项明确的模型假设，**不声称对应实际券商到账日，也不保证所有实际股东五日内到账**。现金在有效日计入应收及净值，释放前不能购买股票；等权组合统一按可动用资产缩放，不能因为代码排列顺序而让前几只股票花完现金。继受股票按经济权益记录，成交仍使用可用的真实次日开盘价和模型成本，不声称已获得券商交割证明。

研究使用可分割的经济权益份额，保留换股后小数股份；不猜测DTV普通股的零股出售价格。整股模拟模式必须取得适用的零股现金规则，缺少时保持未完成；OCC期权结算价格不能代替普通股结算价格。新登记但未明确采用本模型或取得实际到账证据的事件，默认仍为到账未知的应收，不能静默自动放行。
