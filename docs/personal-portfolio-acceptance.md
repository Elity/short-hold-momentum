验证命令：`uv sync --locked`；`uv run shm config validate --config-dir config --require-universe`；`uv run pytest --disable-warnings`；`SHM_BROWSER_CHANNEL=chrome npm run test:browser`。CI 使用安装的 Chromium，无 Chrome 通道覆盖。

浏览器证据为真实后端接口与 SQLite 的闭环；AI 使用返回固定结构的替身服务，未发送真实持仓、未验证用户将配置的外部服务商。生产启用和真实服务商测试必须分别记录，不能以本地替身通过替代。

停止边界：不调整策略、股票池、历史结论或模型参数；不追加研究。部署备份、镜像 SHA、原账本哈希及认证入口状态在交付部署记录中单列。
